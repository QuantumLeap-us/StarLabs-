# StarLabs

![StarLabs](public/logo.png)

## Description

StarLabs is a comprehensive suite of blockchain and automation tools. This project includes wallet generators, proxy checkers, and various automation utilities designed for blockchain interaction and management.

## Features

- **Wallet Generator**: Create wallets for multiple blockchain networks (EVM, TON, SUI, Solana, IBC)
- **Proxy Checker**: Test and validate different types of proxies
- **xAutomator**: Automation tools for various tasks
- **Modern React Frontend**: User-friendly interface for all tools

## Installation

```bash
# Install dependencies
npm install

# Start all services
./start_all.bat
```

## Development

```bash
# Run frontend in development mode
npm run dev

# Build for production
npm run build
```

## Project Structure

- `/projects` - Contains individual project modules
  - `/wallet_generator` - Blockchain wallet generation tools
  - `/proxy_checker_backend` - Backend for proxy validation
  - `/xAutomator_server` - Automation server
  - `/wallets_checker` - Tool for checking wallet balances
- `/src` - Frontend React application
- `/public` - Static assets
